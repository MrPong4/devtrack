
# DevTrack

A full-stack project management platform designed to help individuals and teams organize projects, manage tasks, track progress, and collaborate efficiently.

## About

DevTrack is a portfolio project built to demonstrate full-stack software engineering skills, including backend development, database management, REST API design, and frontend development.

## Technology Stack

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Maven

### Frontend
- React
- JavaScript
- Vite

### Database
- MySQL

### Tools
- Git and GitHub
- Visual Studio Code
- MySQL Workbench

## Planned Features

- User registration and authentication
- Project creation and management
- Task creation, editing, and deletion
- Task priorities and status tracking
- Project dashboards
- Due dates and progress tracking
- Team collaboration
